# Состояния подбора

Все снимки сделаны на работающей главной странице при ширине 1440 px, масштабе 100% и приоритете «Быстро». Вода, соль и растительное масло входят в домашний запас по правилам каталога.

| Состояние | Как получен снимок |
|---|---|
| [Пустая выдача](01-empty.png) | Для риса басмати задан лимит 15 минут и 50 ₽ за порцию. Поиск закончен, подходящих блюд нет. Доступно изменение условий. |
| [Загрузка](02-loading.png) | Введены томаты, 25 минут, 300 ₽ за порцию. В испытании браузер удержал ответ тестового адреса ранжирования. Показан штатный индикатор ожидания и переход к локальной выдаче. Реальный внешний вызов модели для этой проверки не использовался. |
| [Ошибка](03-error.png) | Сначала выбраны томаты и 25 минут. При перезагрузке браузер получил тестовый HTTP 503 вместо файла каталога. Штатное сообщение предлагает повтор. После восстановления файла нажата кнопка «Повторить», томаты и лимит времени сохранились. |
| [Результат](04-result.png) | Рис басмати, куриное филе, морковь и петрушка, до 30 минут и 300 ₽ за порцию. Найдены блюда из выбранных продуктов. Дополнительные варианты с докупкой стоят отдельно. |
| [Частичный результат](05-partial.png) | Томаты, до 25 минут и 300 ₽ за порцию. Сайт показывает блюда с перечислением недостающих ингредиентов. |

У снимков результата и частичного совпадения высота увеличена, чтобы в кадр вошли все предложенные блюда. [Первый визит до поиска](../../practice-3/02-input-1440.png) отдельно показывает исходное состояние формы.
