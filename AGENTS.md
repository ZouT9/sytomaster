# СытоМастер

Перед каждой правкой интерфейса открывай [DESIGN.md](design/practice-4/DESIGN.md) и [tokens.css](handoff/static/css/tokens.css). Проверяй изменённый экран по правилам компонентов и состояний.

При работе с этим проектом сначала открой [рабочую памятку по лекциям 2–5](design/course-checklist.md). В ней есть критерии с номерами страниц, состав каждой практики, принятые пользовательские решения и сверка локальной версии с репозиторием команды.

Для исследования привязывай идеи к задаче пользователя. При изменении экрана зафиксируй исходную версию, конкретную правку и способ её проверить. Перед заявлением о готовности сверь материалы с требованиями соответствующей практики и актуальной веткой команды. Отличай учебный пример, результат работающего сервиса и гипотезу.
